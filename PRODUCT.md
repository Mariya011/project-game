# StudyQuest

Educational web game for a student's IT-class project. Russian interface, desktop and phone.
Subjects: Mathematics, Physics, Russian, Natural Sciences. Each subject is a floating green island.
Learning flow: short theory, practice, final challenge, XP and achievements.
Current scope: redesign the homepage and navigation; lessons and real XP are not implemented yet.
Technical constraint: preserve plain HTML/CSS, add modular vanilla JS for UI and locally hosted GSAP.
Approved palette: sky blue #DFF3FF, green islands #78B85A, emerald actions #246B45, navy #193B56, cream #FFF8E8, restrained gold #D6A43B.
Do not invent completed progress or functioning lessons. Existing topics are proposed learning content.
